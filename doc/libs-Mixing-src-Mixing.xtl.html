librarylibs/Mixing/src/Mixing.xtl

Mixing: residual streams mixed under a constraint. A residual block carries one stream x and adds what a layer computes from it, x + F(x); hyper-connections (Zhu et al., ICLR 2025) carry n streams side by side, a matrix of n rows, and mix them at every layer by an n by n matrix; mHC (Xie et al., 2025) holds that matrix to the doubly stochastic matrices (no entry negative, every row and every column summing to 1). This library: the layer over n streams as mHC writes it, x <- H x + b F(a' x); the streams' mean and differences; the path from the identity to uniform mixing; and how far a matrix is from each kind of mixing (doubly stochastic, orthogonal), with the gain mHC measures. Sinkhorn's iteration, which makes a positive matrix doubly stochastic, is matrix scaling and general: it is asked of X_eTaL-libraries (docs/xetal-libraries-asks.md, GL3), not kept here. Import it with an alias of your choice: "hc:" u_se< "Mixing". Put libs/Mixing/src on XETAL_PATH ("just path"); the reference is libs/Mixing/docs. Names with l: are exported; those under h: are private to this file.

Streams are a matrix with one row per stream (n rows) and one column per coordinate (d columns); a vector is n streams of one number each. A mixing matrix is n by n. Every result is a Float.
