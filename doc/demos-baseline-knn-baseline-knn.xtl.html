programdemos/baseline-knn/baseline-knn.xtl

Baseline, nearest neighbors: k nearest neighbors under the straight-line distance on the three data sets of the kit (flat clusters, directions, a tree), each split the same seeded way, the held-out accuracy and the cost of each run recorded as the experiment schema says; and for the tree, how badly a plain layout of it keeps its distances. The row every comparison of H1 is set against: no geometry chosen yet.

ᵘr̲un : (Float, Int, Int, Int) -> (Float, Int, Int)

ᵘr̲un (X, y, k, seed): one run of k nearest neighbors on the set (X, y) under the straight-line distance (Learn's k_nn), the held-out quarter guessed from the rest; the record, as the schema says: the held-out accuracy (measured), how many were held out, the numbers trained (none: nearest neighbors learns no number) and the operations counted (one distance per held-out point per training point, each of d coordinates); then the held-out rows and the guesses, for a picture. Runtime is never recorded.
