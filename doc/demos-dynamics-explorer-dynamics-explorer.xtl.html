programdemos/dynamics-explorer/dynamics-explorer.xtl

Dynamics explorer, part 1: must a state head downhill? A vector field gives a direction and a size at every point of the plane, dx/dt = v(x); a state that follows it traces a path. Five linear fields v(x) = A x (attractor, rotation, spiral, saddle, expanding spiral): the arrows on a grid, the paths from four starts by a fourth-order Runge-Kutta step beside the exact paths, the divergence and curl of each by central differences beside the exact values, the sum of v . dx round a loop (zero for a field that is minus the gradient of a loss, not for one that turns), and the stability of the rest point from the trace and determinant of A. Then integration as a choice: Euler's step against Runge-Kutta's on the rotation, whose exact paths are circles, at four step sizes. And as machine learning meets it: gradient descent on a loss (a gradient field: it settles) beside simultaneous descent and ascent on the two-player objective f(x, y) = x y (a rotation: it spirals out), with two known repairs, the players taking turns and a look-ahead step (extragradient), from the same start at the same rate.

ᵘf̲low : (Float, Float) -> Float

function · line 84

For a linear field the exact path is x(t) = exp(t A) x0, and for a 2 by 2 matrix exp(t A) has a closed form: write A = tau I + B with tau half the trace, so B has trace 0 and B B = -det(B) I. Then exp(t A) = e^(tau t) (cos(w t) I + sin(w t) / w B) when det B > 0 (w = sqrt det B: the path turns), the same with cosh and sinh when det B < 0 (w = sqrt -det B), and e^(tau t) (I + t B) when det B = 0.

ᵘl̲oop : (Float, Float) -> Float

function · line 128

Walk round a closed loop and add up v . dx along it: for each straight piece, the field at its middle dotted with the piece (exact for a linear field, which changes linearly along the piece). If v is minus the gradient of a loss L, each piece adds L(start) - L(end) of that piece, so the whole loop adds 0: the "height" comes back to itself. Green's theorem says the sum is the curl times the area enclosed, and the flow out across the loop (v dotted with the outward normal, (dy, -dx) when the loop runs anticlockwise) is the divergence times the area. The loop: a regular polygon of loopN pieces on the unit circle.

ᵘd̲escent : Float -> Float

function · line 226

Gradient descent on the loss L(x, y) = (x^2 + y^2) / 2: the step p - eta (x, y) follows the field minus the gradient of L, an attractor; it settles. A two-player game: player one picks x to make f(x, y) = x y small, player two picks y to make it large. Each steps along its own slope at the same rate: x - eta y (down f), y + eta x (up f). Taken together that is the field (-y, x), the rotation, stepped by Euler's rule, and it spirals out from the solution (0, 0), where neither player can do better alone. Two repairs, from the papers (docs/papers.md): the players take turns, the second answering the first's new x (bounded, it circles and keeps x^2 + y^2 - eta x y fixed, Bailey, Gidel and Piliouras 2019); and a look-ahead step (extragradient, Korpelevich 1976, analyzed on this game by Gidel et al. 2019): both step to a trial point, then step from the start along the slopes found at the trial point. The same start, rate and number of steps for all four.

ᵘd̲escent ← { p → p − eta × p }
